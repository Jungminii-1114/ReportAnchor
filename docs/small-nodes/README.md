# Small Node — 개별 계약 문서 목록

> **정본:** 각 Small Node의 단일 책임·내부 함수·입출력·실패 상태를 관리한다. Big Node별 사용 예시나 노드 간 조건부 엣지는 포함하지 않는다.
>
> **현재:** N-01은 책임·입출력 개념 필드·후보 0건 상태 분류 확정. N-02도 **고정 길이 확장·입출력 개념 필드·예외 처리·원문 오프셋 규칙 확정**, 실제 Python 스키마·확장 길이·구현은 미정이다. N-03은 **무참조 주장 생략·규칙 기반 수치/날짜·동일 모델 별도 세션의 단일 LLM Judge·상위 ID 재사용·최소 출력 필드·예외 처리·출력 구조도**를 확정해 **MVP 개념 설계를 완료**했으며, Python 스키마·구현·테스트는 미완료다. N-04는 **A 방식(`answer + claims[]`)·문장 단위 주장 추출·입출력 개념 계약·부분 답변(`partial_answer`)·전체 무참조 사실 답변 차단을 포함한 예외 처리**까지 확정했으며, 실제 Python 타입·구현/테스트는 미완료다. N-06/N-09는 N-03과의 요청·주장 ID 연동 규칙만 확정했으며, N-05는 복합 기준 B 방식 분해를 확정했으나 입출력 상세/내부 워크플로는 검토 중이다. N-06~N-11의 나머지 상세 계약은 미정이다.
>
> **공통 반환 계약(확정 2026-11-01):** **[NodeResult[T] — 공통 블록·상태·단계별 진단·시각화](common-result-contract.md)**. N-01~N-11의 모든 반환은 `status`, `data`, `diagnostics`, `outcome` 4필드를 사용한다.

| Small Node | 역할 | 설계 상태 |
|---|---|---|
| [N-01 · `retrieve_evidence`](N-01.md) | 검색 후보 탐색 | 입출력 개념 계약·상태 처리 확정 / 상세 타입·검색 설정 미정 |
| [N-02 · `get_source_context`](N-02.md) | 원문 위치 매핑·고정 길이 문맥 확장·출처 보존 | 입출력·예외·오프셋 규칙 확정 / 실제 타입·구현 미정 |
| [N-03 · `verify_grounding`](N-03.md) | 주장·판정·비교 결과와 원문 근거의 정합성 검사 | **MVP 개념 설계 완료 (입출력·흐름·상태·구조도)** / 구현·테스트 미완료 |
| [N-04 · `draft_answer`](N-04.md) | 원문 근거를 이용한 질문 답변 초안 작성 | 문장 단위 A 방식·부분 답변·전체 무참조 답변 차단 확정 / 구현 미완료 |
| [N-05 · `structure_criteria`](N-05.md) | 명시된 검토 기준을 판정 항목으로 구조화 | **복합 기준 B 방식 분리 확정** / 내부 워크플로·상세 입출력 미정 |
| [N-06 · `evaluate_criterion`](N-06.md) | 기준별 충족·미충족·확인 불가 판정 | 기준별 추적 ID 전달 규칙 확정 / 상세 계약 미정 |
| [N-07 · `define_comparison`](N-07.md) | 문서·기간·지표·범위 및 비교 축 정의 | 책임/최소 입출력 등록, 상세 미정 |
| [N-08 · `check_comparability`](N-08.md) | 기간·단위·집계 조건과 정성 비교 범위 검사 | 책임/최소 입출력 등록, 상세 미정 |
| [N-09 · `build_comparison`](N-09.md) | 정량 계산 또는 정성 비교 결과 구성 | 비교별 추적 ID 전달 규칙 확정 / 상세 계약 미정 |
| [N-10 · `route_query`](N-10.md) | 요청·권한·범위 확인과 작업 선택 | 책임/최소 입출력 등록, 상세 미정 |
| [N-11 · `deliver_result`](N-11.md) | 검증된 결과·출처·상태 전달 | 책임/최소 입출력 등록, 상세 미정 |
