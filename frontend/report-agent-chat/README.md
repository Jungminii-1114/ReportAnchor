# Report Agent Chat — 대화형 UI

기존 `report-agent`의 4단계 UI를 유지하면서 별도로 만든 대화형 버전입니다.

## 바로 보기

`preview.html`을 더블클릭하세요. 이 파일 하나만 전달해도 예시 PDF와 채팅 UI를 볼 수 있습니다.
새 미리보기 탭은 **찾는 중** 상태로 시작하고, 자동으로 예시 문서를 찾은 뒤 안내가 사라집니다. 같은 탭을 새로고침하면 진행 상태를 유지합니다.
문서를 찾으면 문서를 찾았습니다 안내를 약 2.5초 표시한 뒤 숨깁니다. 파일명 카드가 계속 표시되지는 않습니다. 추천 질문 또는 직접 입력으로 대화를 시작하세요. 평가 기준은 입력창 아래 버튼으로 추가합니다.
근거 확인을 펼치면 인용문과 원문 페이지 버튼이 나옵니다. 패널 안의 **PDF 크게 보기** 버튼을 누르면 패널이 닫힙니다. 다시 열 때는 Chrome 도구 모음에 고정한 Report Agent 확장 아이콘을 누릅니다. 미리보기 오른쪽 위 아이콘은 이 도구 모음 아이콘을 나타내는 모형입니다.

## Chrome 확장 프로그램 실행

Chrome 141 이상이 필요합니다. 설치 후 확장 메뉴에서 Report Agent Chat을 고정하면 다시 열기 쉽습니다.

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 개발자 모드를 켭니다.
3. 압축해제된 확장 프로그램을 로드합니다를 선택하고 이 프로젝트의 `dist` 폴더를 지정합니다.
4. 도구 모음에서 **Report Agent Chat**을 눌러 사이드 패널을 엽니다.

기존 Report Agent와 별도의 확장 프로그램으로 설치할 수 있습니다. 실제 확장에는 브라우저 모형이나 왼쪽 예시 PDF가 표시되지 않습니다. 확장 UI는 예시 문서가 연결된 상태로 시작합니다.
상단 전체화면은 새 탭에서 대화를 넓게 엽니다. 사이드 패널과 전체화면의 대화, 작성 중인 질문, 평가 기준, 답변 생성·중단 상태가 실시간으로 연동됩니다. 전체화면 상단의 사이드 패널로 돌아가기 버튼으로 원래 문서 탭과 패널로 돌아갈 수 있습니다. 미리보기에서는 원래 미리보기 창으로 돌아갑니다. 전체화면은 새 탭 확장 보기이며 브라우저 F11 모드는 아닙니다.

## 개발 및 빌드

Node.js 20.19 이상을 설치한 뒤 이 폴더에서 실행하세요.

```sh
npm install
npm run dev
npm run build
```

`npm run build`는 확장 설치용 `dist`와 단독 실행용 `preview.html`을 만듭니다.
직접 파일로 열 때는 `index.html`이 아니라 `preview.html`을 사용하세요.

## 파일 역할

- `src/App.jsx`: 대화, 문서 상태, 입력 및 응답 대기 동작을 관리합니다.
- `src/components/Answer.jsx`: 답변, 평가 결과, 근거와 후속 질문을 표시합니다.
- `src/components/PreviewShell.jsx`: 미리보기 전용 브라우저 모형과 예시 PDF를 표시합니다.
- `src/data/mockResponses.js`: 시연용 질문과 고정 응답입니다. 백엔드 연결 시 교체할 부분입니다.
- `src/data/samplePdf.js`: 단독 미리보기에 포함하는 예시 PDF 데이터입니다.
- `src/styles.css`: 채팅 UI와 반응형 스타일입니다.
- `src/preview.css`: 미리보기 브라우저 모형의 스타일입니다.
- `public/manifest.json`: Chrome 확장의 이름, 권한, 사이드 패널을 설정합니다.
- `public/background.js`: 확장 아이콘을 누르면 사이드 패널을 엽니다.
- `scripts/build.mjs`, `scripts/build-preview.mjs`: 확장 및 미리보기 파일을 생성합니다.

## 구현 범위

실제 PDF 감지, PDF 분석, AI 대화, 파일 다운로드는 구현하지 않았습니다. 입력 키워드에 따라 고정된 예시 답변을 선택하고 잠깐 기다린 뒤 보여줍니다. 평가 기준의 실제 판정도 하지 않습니다. 원문 이동은 미리보기의 예시 PDF에서만 동작합니다.
대화는 미리보기에서 브라우저 로컬 저장소에, 확장에서 Chrome 세션 저장소에 저장합니다. 새 대화 버튼을 누르면 비웁니다. 미리보기와 실제 확장은 서로 저장 공간이 분리됩니다.

실제 기능 연결 시 App의 문서 연결 및 ask 동작을 문서 감지/API 호출로 바꾸고, 응답 데이터를 Answer 컴포넌트에 전달하세요. PreviewShell은 확장 빌드에서 사용하지 않습니다.

- src/services/chatState.js: 화면 사이에 공유하는 대화 상태와 저장·동기화를 담당합니다.
- src/services/expandedView.js: 전체화면 열기와 원래 사이드 패널로 돌아가기를 담당합니다.

전체 기능의 구현 여부와 미구현 항목은 `FEATURE-AUDIT.md`를 참고하세요.
