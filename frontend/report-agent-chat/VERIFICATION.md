# 검증 결과

## 실제 PDF 인식 추가 — 2026-11-28

### 판별 함수 테스트

테스트 스크립트(`npm test`와 동일한 `node --test tests/*.test.mjs`)로 37개 테스트를 통과했습니다.

- PDF 주소, 한글 파일명, 대소문자 및 페이지 해시 처리.
- 확장자가 없는 주소의 `application/pdf` 응답 인식.
- HTML 응답, HTTP 오류 및 다른 URL의 오래된 응답 기록 제외.
- 문서 로딩 상태와 로컬 파일 접근 권한 안내.
- Chrome 내부 화면, blob 주소 등 지원하지 않는 주소 구분.
- 이전 요청의 지연 이벤트 제외, 새로고침·리다이렉트·PDF 뷰어 전환 중 요청 취소 처리.

### 실제 Chrome 확장 연결 테스트

실제 Chrome에 빌드된 Manifest V3 확장을 로드하고, 테스트 서버가 제공하는 PDF 및 HTML 응답으로 확인했습니다. 패널 페이지와 전체화면 페이지에서 실제 확장 API와 세션 저장소를 사용했습니다.

- `.pdf` 주소와 확장자가 없는 PDF 주소에서 실제 응답 MIME을 확인하고 문서를 연결함.
- `.pdf` 주소여도 HTML 로그인 화면 또는 404 응답이면 연결하지 않음.
- 문서 이동 시 이전 대화와 진행 중 예시 응답을 초기화함.
- 전체화면을 열어도 원래 PDF 연결을 유지하고 질문 초안을 동기화함.
- 다른 PDF로 바꾼 뒤 전체화면을 새로고침해도 이전 문서로 되돌아가지 않음.
- 문서 변경 전에 시작한 예시 응답이 새 문서 대화에 추가되지 않음.
- 사이드 패널로 돌아가기 버튼으로 현재 연결된 문서 탭을 활성화함.
- 원래 문서 탭을 닫으면 오류 안내를 표시하고, 다시 찾기를 사용할 수 있음.
- 로컬 PDF에서 Chrome의 파일 접근 허용 여부에 맞는 상태를 확인함.
- 파일 접근이 허용된 로컬 PDF의 실제 인식을 확인함. 권한이 꺼진 경우의 안내는 판별 함수 테스트로 확인함.
- 확장 화면 320 / 380 / 600px에서 긴 오류 안내의 가로 넘침 없음.

### 미리보기 및 빌드

- 단독 `preview.html`에서 찾는 중 → 찾음 → 안내 숨김 동작 유지.
- 예시 질문 전송, 예시 답변, 새 대화 확인.
- 미리보기 320 / 380 / 700 / 1440px에서 가로 넘침 없음.
- 확인한 확장 및 미리보기 화면에서 JavaScript 실행 오류 없음.
- 확장 설치용 `dist`와 단독 미리보기 빌드 성공.

## 검증 범위

이번 변경은 열린 탭의 **PDF 주소 및 응답 메타데이터 인식**입니다. PDF 본문 읽기, 파싱, AI 분석, 실제 근거 페이지 연결은 아직 구현하지 않았습니다. 찾은 문서가 실제 PDF여도 답변은 고정 예시입니다.

이미 열린 확장자 없는 PDF는 확장 설치·실행 후 한 번 새로고침해야 응답 정보를 확인할 수 있습니다. 응답 기록이 없는 `.pdf` 주소는 주소 기준 식별이며 파일 내용 검증이 아닙니다. blob 주소, 사이트 자체 뷰어, 웹페이지에 삽입된 PDF는 지원하지 않습니다. 현재 검토 문서는 두 화면에서 하나를 공유합니다.

## 기존 화면 제어 검증 기록

이전 작업에서 실제 Chrome의 사이드 패널 열기·닫기·재열기, 초안 보존, 전체화면 양방향 동기화와 예시 답변 중단을 확인했습니다. 미리보기의 예시 PDF 뷰어는 실제 확장 화면에 포함되지 않습니다. 기존 4단계 버전은 이번 변경 대상이 아닙니다.
