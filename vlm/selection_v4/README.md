# 고정 선정 규칙 v4

기존 세 방식 비교 결과는 유지하고, ③ Docling+Python 방식에 다음 조건을 추가한 실행용 버전이다. 문서명·페이지 번호별 예외는 사용하지 않았다.

| 보완 | 실제 조건 |
|---|---|
| 기본 표가 확보됐는데 추가 선정되는 경우 억제 | 기본 표와 후보의 경계가 충분히 일치하고, 기본 표에 None이 없고 행별 열 수가 일정하며 헤더 표현이 2개 이상 있고, 원문 영역의 검사 대상 단어가 셀 문자열에 모두 존재하면 파싱 결과 활용으로 분류. 의미 정확도 인증은 아님. |
| 페이지 전체 글자 수가 누락을 가리는 문제 | 페이지 텍스트가 50자 이상이어도 큰 이미지 내부에 기본 추출 문자가 전혀 없으면 검사. 세로로 연속된 이미지 조각을 묶고, 면적 2% 이상·폭 20% 이상·높이 4% 이상이며 기존 후보가 90% 미만 포함하면 주황 검토 후보 추가. 사진 분류 점수 0.9 이상인 영역은 이 추가 경로에서 제외. |
| 목차 번호를 수치로 선정하는 문제 | 명시적 목차 제목, 또는 숫자 시작 항목 6개 이상과 기관명 표현 3개 이상, 또는 개요 제목과 오른쪽 열의 독립 번호 4개 이상이 있는 문맥에서 1~3자리 독립 번호를 지표 후보에서 제외. |

## 전체 적용 결과

전체 172페이지에 적용했다. KISTEP 7·8p에 이미지 영역 검토 후보를 각각 1개 추가했고, ETRI 13·37p에서 목차 번호 후보 3개·4개를 제외했다. 나머지 페이지의 선정 결과는 유지됐다. 코드 해시는 results/frozen.json에 고정했다.

관찰한 오류를 바탕으로 만든 개발 버전이다. 모든 PDF에 일반화됐다는 뜻은 아니다. OCR 오인식·본문 누락·도식 연결 관계·과도한 영역 통합은 아직 완전히 해결하지 못했다. VLM 실행용으로 이 버전을 고정하고, 이후 성능은 실제 추출 결과로 별도 평가한다.

## 파일과 실행

- selection_assessment.md: 기본 파서 기준 네 가지 판정 표.
- refine_and_freeze.py: 보완 코드.
- results/KISTEP.json, ETRI.json, AX.json: VLM 실행에 사용할 페이지별 선정 결과.
- results/frozen.json: 버전·해시·적용 범위.

기존 전체 결과 폴더와 원본 PDF를 사용해 재실행할 때:

```bat
python refine_and_freeze.py --root "기존_vlm_selection_full_폴더" --pdf-dir "PDF_3개가_있는_inputs_폴더" --output results
```

기존 기본 파싱이나 Docling을 다시 실행할 필요는 없다. 이 코드는 저장 결과와 PDF 좌표를 사용하며 VLM을 호출하지 않는다. 이번 묶음에 VLM 추출 결과는 없다.
