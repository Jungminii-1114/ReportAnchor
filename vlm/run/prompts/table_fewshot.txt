첨부 이미지의 표 본체에 있는 수치 셀을 구조화하세요.
보조 파서 텍스트의 읽기 순서를 그대로 믿지 말고 이미지로 행과 열을 확인하세요.
표 밖의 설명문, 주석, 헤더 안의 숫자는 cells에 넣지 마세요.
설명문으로 구성된 열 안의 숫자는 제외하고, 수량·금액·비율·증감 등 수치 열을 추출하세요.

규칙:
- 객체 하나에 원문 수치 셀 하나만 저장하세요. 합계와 증감도 포함하세요.
- 수치 열의 '-' 표시도 셀 하나로 보존하고 0으로 바꾸지 마세요.
- row_path는 해당 셀을 설명하는 상위부터 하위까지 행 항목입니다.
- column_path는 해당 셀 위에 있는 상위부터 하위까지 열 헤더입니다.
- 나란히 있는 서로 다른 행이나 열을 하나의 경로에 합치지 마세요.
- 행 항목의 이름을 설명하는 '구분' 같은 헤더를 column_path에 넣지 마세요.
- 병합된 상위 행·열 헤더는 각 하위 셀의 경로에 반복해 포함하세요.
- 원문의 헤더 이름, 연도 표기, 괄호와 주석 기호를 보존하세요.
- 편집상 공백과 줄바꿈은 정리하되 의미가 있는 단어를 누락하지 마세요.
- value_raw는 쉼표, %, 감소 기호를 포함한 원문 문자열입니다.
- unit은 표에 명시된 공통 단위 또는 해당 열의 단위를 반복 기록하세요.
- 단위를 추론해서 추가하지 마세요. 명시된 단위가 없으면 빈 문자열입니다.
- table_title은 독립적인 표 제목이 있을 때만 기록하고 없으면 빈 문자열입니다.
- 표 아래 주석은 최상위 notes에 저장하세요.
- 읽을 수 없는 값은 빈 문자열로 남기고 issues에 사유를 기록하세요.
- 아래 형식의 JSON 객체 하나만 반환하세요.
{
  "table_title": "",
  "cells": [
    {
      "row_path": ["행 항목"],
      "column_path": ["상위 헤더", "하위 헤더"],
      "value_raw": "원문 값",
      "unit": "",
      "notes": [],
      "issues": []
    }
  ],
  "notes": [],
  "issues": []
}

다음은 현재 이미지와 무관한 가상 표의 작성 예시입니다. 예시의 항목과 숫자는 실제 출력에 복사하지 마세요.

가상 표 구조:
- 첫 번째 열은 행 이름 열이며 제목은 '구분'입니다.
- 오른쪽 두 수치 열은 병합 헤더 '서비스인력' 아래에 '기획', '지원'이 있습니다.
- 데이터 행은 '본사'이며 두 수치 셀은 각각 8, 6입니다.
- 표에 단위는 명시되어 있지 않습니다.
이 경우 첫 수치 셀은 다음과 같습니다:
{"row_path":["본사"],"column_path":["서비스인력","기획"],"value_raw":"8","unit":"","notes":[],"issues":[]}
'서비스인력'은 해당 수치 열을 덮는 상위 헤더이므로 포함하고, '구분'은 왼쪽 행 이름 열의 제목이므로 포함하지 않습니다.

다른 가상 예시에서 하나의 헤더 셀에 '계획(내부 승인)'이 두 줄로 적혀 있다면 경로 요소 하나인 "계획(내부 승인)"으로 옮깁니다.
하나의 열 헤더가 '달성률(%)'이면 닫는 괄호까지 그대로 보존합니다.
예시는 작성 방식만 설명합니다. 실제 헤더·행 항목·값·단위는 첨부 이미지에서 읽으세요.
