# 세 가지 선택 기준

이 문서의 규칙은 실행 중 문서별로 조정하지 않았다. 문서명·페이지 번호·정답 수치는 분기 조건으로 사용하지 않는다. 후보란 추가 VLM 처리 또는 검토 대상이며, VLM이 더 잘 추출한다는 보장은 아니다.

## ① 기본 파서 + Python 신호

기존 전체 172p의 `parser_python.json`을 재사용했다.

- 내용은 있으나 기본 텍스트가 50자 미만이면 텍스트 부족 신호.
- 작은 미세 점만 있는 페이지는 본문 영역의 어두운 픽셀 유무를 함께 보고 빈 페이지 후보로 분리.
- 텍스트 부족 페이지의 이미지 중 페이지 면적 2% 이상·가로세로 40pt 이상이며 영역 텍스트도 부족한 이미지를 후보로 둠.
- 해당 이미지가 없으면 페이지 전체를 검토 후보로 둠. 사진·도식의 의미를 분류하지 않음.
- 검출 표에 None 셀, 빈 첫 행 헤더, 행별 셀 개수 불일치가 있으면 구조 검토 신호. 병합에 따른 정상 None도 있으므로 파싱 오류로 확정하지 않음.

이번 ①은 위 후보 신호를 기준으로 한다. 선·격자 교차점 검출은 이전 대표 실험의 별도 방식이며, 이번 전체 후보 집계에 섞지 않았다.

## ② Docling 요소·분류 기반 후보 기준

Docling standard로 각 페이지의 OCR·레이아웃·표 구조·그림 분류를 얻었다. 그 출력에 아래의 고정된 후보 정책을 적용했다.

- 검출된 표는 모두 넓은 비교 기준의 후보로 둠. 이미 잘 추출된 표도 포함될 수 있음.
- 그림 최상위 분류가 사진·로고·아이콘·서명·QR·바코드·도장이고 점수 0.9 이상이면 추가 VLM 제외.
- 분류가 없거나 other·full_page_image·page_thumbnail 또는 점수 0.6 미만이면 검토 대상으로 둠.
- 그 외 표·차트·도식·지도 등의 그림은 후보로 둠.
- 일반 OCR 텍스트는 이 기준만으로 VLM에 보내지 않음.

위 점수·정책은 이 실험에서 선택한 기준이다. Docling 공식 VLM 필요성 판정 규칙이나 정답 확률을 의미하지 않는다. 그림 분류 enrichment를 켰고, 그림 설명용 VLM은 사용하지 않았다.

## ③ 고정 Docling + Python 보완 규칙

이전 대표 14p에서 개발한 `docling-context-routing/2`를 고정한 뒤 전체에 적용했다. 이번 전체 결과를 보고 임계값을 추가 수정하지 않았다.

- Docling 표 단위 보존: 병합·빈 헤더·셀 정보 부족은 검토, 해당 신호가 없으면 기본 추출 유지. 내용 검증 완료는 아님.
- 사진 점수 0.9 이상이어도 내부 OCR·캡션의 수치 신호가 있으면 단순 제외하지 않음.
- 작은 장식은 점수 0.9 이상, 페이지 면적 1% 미만, 내부 OCR·캡션 없음일 때만 제외.
- 나란히 정렬된 작은 그림이 2개 이상이고 가로 범위가 페이지 폭 15% 이상이면 인접 글자와 함께 도식 문맥 검토 영역으로 묶음. 이 그룹 안의 작은 장식을 제외 목록에서 회수.
- 표·그림이 이미 포함하는 수치를 중복 선정하지 않음.
- 짧은 독립 수치·단위·순위 표현을 보존. `374조원`, `248조 원`, `세계 5위` 등을 항목명으로 해석하지 않고 문맥 영역으로 남김.
- 연도·날짜 및 작은 단독 번호의 독립 지표 후보를 억제.
- 수치 주변 창은 페이지 크기에 비례해 확장하고, 같은 높이의 다른 수치와는 중간 지점에서 경계를 제한. 가까운 글자를 항목명이라고 확정하지 않음.
- 같은 상태의 포함 중복을 정리하고, 가까운 앞쪽 절 제목을 출처 있는 문맥으로 연결.

사진·장식 제외는 원문·OCR 삭제나 큰 입력 이미지에서 해당 픽셀을 지우는 것이 아니다. 해당 작은 영역을 별도 VLM 호출 목록에서 제외하는 것이다.

## 결과 상태

- 빨강 `vlm_candidate`: 규칙상 추가 VLM 후보.
- 주황 `review_required`: 보완 필요성·구조·경계가 불확실한 검토 대상.
- 초록 `exclude_vlm`: 추가 VLM 후보에서 제외. 원문과 추출 정보는 보존.
- 파랑 `parser_only`: 확보된 파싱 결과를 활용. 이 비교에서는 Docling의 OCR·표 구조도 포함하며, PyMuPDF가 읽었다는 뜻은 아님. 내용 정확도 검증 완료는 아님.

집계의 후보/검토 수는 빨강과 주황을 합산한다. 초록·파랑은 후보 수에서 제외한다. 후보 수가 작아졌다는 이유만으로 성능 개선이라고 판단하지 않는다.
